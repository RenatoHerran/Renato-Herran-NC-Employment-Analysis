# Renato Herran - NC Employment Analysis
Final Project Data Analytics

North Carolina Labor Market Analysis (2016–2026)
This project analyzes how unemployment, employment levels, and wages interact in North Carolina over time. Using BLS data, the goal is to identify trends and explain what drives wage growth.

Data
U.S. Bureau of Labor Statistics (BLS)
Supporting data from Data.gov

Methods
Excel (cleaning + regression)
Tableau (visualizations)
Trend and correlation analysis

Key Findings
Weak relationship between unemployment and wages (R² ≈ 0.10)
Strong positive relationship between employment and wages (R² ≈ 0.69)
COVID-19 (2020) caused major labor market disruption

Employment growth is a key driver of wages, but other factors also influence wage changes over time.
